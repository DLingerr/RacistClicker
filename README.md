# RacistClicker

A personal auto clicker for Windows with accurate CPS timing, global hotkeys and an optional overlay.

## Download

Installers are on the [Releases page](https://github.com/DLingerr/RacistClicker/releases/latest).

## Building from source

See [BUILDING.md](BUILDING.md). In short: install Node.js, Rust and the Microsoft C++ Build Tools, then run `npm install` and `npm run dev`.
